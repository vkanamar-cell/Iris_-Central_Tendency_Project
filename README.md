# Data Preprocessing using Python

## Overview
This project demonstrates common data preprocessing techniques using Python and the CAR dataset.

## Features
- Read Excel dataset
- Handle missing values
- Remove duplicate records
- Label Encoding
- Min-Max Normalization
- Save preprocessed dataset

## Technologies Used
- Python
- Pandas
- Scikit-learn
- OpenPyXL

## Files
- CAR.xlsx
- CAR_Preprocessed.xlsx
- data_preprocessing.py

## How to Run

```bash
pip install -r requirements.txt
python data_preprocessing.py
```

## Output
The cleaned dataset is saved as `CAR_Preprocessed.xlsx`.
